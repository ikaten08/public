# 音声入力SOAPノート (Voice SOAP Notes)

ブラウザの Web Speech API を活用した、医療・介護・リハビリ職向けの音声入力＆自動SOAP分類Webアプリケーションです。

---

## 主な機能

1. **ワンクリック音声入力**
   - 「録音開始」ボタンを押すだけで、ブラウザの Web Speech API を介してリアルタイムに音声を文字起こしします。
   - 発話中のテキストをリアルタイムでプレビュー表示し、確定した文を自動追記します。
   - 録音中のアニメーション表示とステータス表示で録音状態が一目でわかります。

2. **SOAP自動振り分け（キーワード分析）**
   - 「SOAP変換」ボタンを押すと、入力テキストを文単位に自動分割し、キーワードを元に S / O / A / P に瞬時に振り分けます。
   - **S（Subjective：主観的情報）**: 「痛い」「つらい」「しびれる」「だるい」「動かしにくい」「不安」「眠れない」「訴え」など
   - **O（Objective：客観的情報）**: 「ROM」「MMT」「度」「cm」「kg」「mmHg」「回」「秒」「歩行」「握力」「バイタル」「腫脹」「熱感」「発赤」など
   - **A（Assessment：評価・分析）**: 「考えられる」「原因」「問題」「改善」「低下」「制限」「リスク」「評価」など
   - **P（Plan：計画・方針）**: 「プログラム」「目標」「実施」「継続」「指導」「週」「回」「セット」「退院」「自主トレ」など
   - 該当しない文は「未分類」カードに集約されます。

3. **直感的な編集＆手動カテゴリ変更**
   - 自動分類後、各文のドロップダウンから手動で「S」「O」「A」「P」「未分類」をワンクリックで変更できます。
   - 不要な文の削除（✕ボタン）も可能。
   - マッチしたキーワードがタグ形式（`#痛い`, `#ROM` 等）でハイライト表示されます。

4. **コピー＆カルテ連携**
   - 「まとめてコピー」ボタンで、日時付きのSOAPフォーマットテキストを一括コピーできます。
   - S, O, A, P 各カードごとの個別コピーボタンも搭載。

5. **サンプル読み込み＆テスト機能**
   - マイクが利用できない環境や動作確認用に、「サンプル読込」ボタンを押すと一発で動作を確認できます。

6. **洗練されたデザイン & レスポンシブ**
   - 白背景ベースのクリーンで現代的なUI。
   - S=青、O=緑、A=黄、P=赤 の視認性の高いカラーリング。
   - PC、タブレット、スマートフォン（スマホサイズ）に完全対応。

## 使い方・起動方法

Web Speech API はブラウザのセキュリティ仕様上、`http://` または `https://` 環境で動作させることを推奨します（`file://` 直開きではマイクアクセスがブロックされるブラウザがあります）。

### ローカルサーバーで起動する場合（推奨）

ターミナルで以下のコマンドを実行します：

```bash
cd /Users/masahiro-takakuwa/.gemini/antigravity/scratch/soap-voice-notes
python3 -m http.server 8080
```

その後、ブラウザ（Google Chrome 推奨）で下記URLを開きます：
👉 **http://localhost:8080**

### 推奨ブラウザ
- **Google Chrome**（最も音声認識精度が高く安定しています）
- **Microsoft Edge**
- **Safari**（iOS / macOS）
